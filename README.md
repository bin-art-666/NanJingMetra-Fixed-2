# 南京地铁（修复版）

南京某大学数据结构课程设计，修复版。

本项目使用 C++、EasyX 和 Visual Studio 实现南京地铁线路展示与换乘查询。程序提供图形化线路界面，可查看单条或全部线路，并支持按最少站点数和最少换乘次数查询起点到终点的路线。

## 修复内容

- 修复 UTF-8 源文件在 Visual Studio 中编译时产生的中文解析错误。
- 修复线路按钮和地铁站名称乱码。
- 修复控制台中文输出乱码。
- 修复起点、终点输入框无法弹出的问题，并支持中文站名输入与回显。
- 恢复图形界面操作对应的终端同步输出。
- 修复线路按钮点击范围判断错误。
- 修复 `find_i_j` 并非所有执行路径都返回值的编译警告。

## 开发环境

- Windows
- Visual Studio（项目当前使用 `v145` 平台工具集）
- C++20
- EasyX 图形库
- x64 构建配置

## 构建与运行

1. 安装 Visual Studio 的“使用 C++ 的桌面开发”工作负载。
2. 安装 EasyX，并确保 Visual Studio 可以找到 `easyx.h` 和对应库文件。
3. 使用 Visual Studio 打开 `NanJingMetra.slnx`。
4. 选择 `Debug | x64` 或 `Release | x64`，然后生成并运行项目。

项目已启用 `/utf-8` 编译选项，请保留该设置，以确保中文源码、界面文字和终端输出正常。

## 使用方法

- 点击左侧线路按钮，可在主界面查看对应线路。
- 点击“全部”或“全部（简洁）”，可切换完整线路图的显示方式。
- 点击起点或终点输入框，在弹出的对话框中输入中文站名。
- 点击“查询（短）”查询最少站点数路径。
- 点击“查询（少）”查询最少换乘路径。
- 图形界面操作及查询结果会同步输出到终端窗口。

## 说明

本项目用于数据结构课程设计与学习交流。线路和站点数据为项目内硬编码数据，仅供演示，实际线路信息请以南京地铁官方发布为准。
